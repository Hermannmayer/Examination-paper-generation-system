    难度配比

    按难度权重分配题量。例如「易 5 / 中 3 / 难 2」表示各难度占 50% / 30% / 20%（合计多少都行，会自动按比例换算）。 全部留空 = 不限难度；某个难度的题不够时会从其他难度借调并提示。

    知识点

    勾选后只在所选考点内出题，并尽量保证每个考点至少出现一题。 不勾选 = 不限知识点。适用场景：需要覆盖多个章节的单元测验。

    未选择（不限知识点）
