# 考试试卷生成系统

把 Excel 题库变成排好版的试卷与答题卡，导出 Word / PDF，直接打印就能用。

一个**本地单机小工具**：双击运行，不装数据库、不联网、不注册账号。数据全部留在
你自己的电脑上。

**适合谁用**：要自己出卷的老师、培训机构、企业内部考核。把手头整理好的题目放进
Excel，几分钟出一套卷子，不用手工排版。

## 三分钟上手

1. **准备题库** —— 打开程序点「示例」，先用自带的小学语文题库（130 题）试试手感。
   要用自己的题，按[下面的格式](#准备你的-excel-题库)整理成 Excel 即可。
2. **配置试卷** —— 左侧从上到下依次是题库、试卷信息、组卷方式、筛选条件、输出。
   大多数选项留空就是默认行为。
3. **看预览** —— 右侧会显示试卷的**真实排版**，改配置会自动刷新。
4. **导出** —— 选个输出目录，勾选要 Word 还是 PDF，点「导出试卷」。

不想要答题卡、不设难度配比、不管知识点，都完全没问题 —— 不填就是不用。

## 功能详解

### 四种题型

| 题型 | 录入方式 | 试卷上 |
|------|----------|--------|
| **判断题** | 答案填 `1`（对）或 `0`（错） | 题干后留一条作答线 |
| **单选题** | 答案填 `A`~`E`，选项填在「选项A」…列 | 选项横向排列 |
| **多选题** | 答案直接连着填 `ABD` | 同上 |
| **简答题** | 答案填参考答案全文 | 题干后自动留作答横线 |

- 四种题型可以**混着出**，在界面上用 ↑↓ 调顺序，每种题型单独设分值。
- 判断题的答案也接受 `√` / `×` / `对` / `错`，程序会统一处理，
  不必为了迁就格式改你原来的题库。
- **简答题**的参考答案会单独排在答案页的最后（成段文字没法压进选择题那种
  「1-5: A B C D」的紧凑格式）。
- **作答空间跟着答题卡走**：不勾答题卡时，试卷上给判断题留作答线、给简答题留
  三行横线（学生直接写在试卷上）；一旦勾了答题卡，试卷上这些横线就**全部去掉**，
  学生改在答题卡上作答 —— 否则是白白占版面。界面上的提示条会说明这一点。

### 三种抽题方式

**随机抽取** —— 最常用。每种题型填个数，程序从题库里随机抽。
同一次配置抽到的题是固定的，所以预览看到的和导出的一定是同一份。

**按比例导出** —— 你只关心题型占比、不想逐个算数量时用。填百分比，程序自己分：

> 判断 30 / 单选 50 / 多选 20，总题数 50 → **15 / 25 / 10 题**

合计不必等于 100 —— 填 `3 : 5 : 2` 和填 `30 : 50 : 20` 结果完全一样，
程序会按比例换算。除不尽的零头按小数部分分配，不会出现「设 40% 实得 70%」那种事。

**顺序导出** —— 想让卷子按题库原顺序出（比如按章节顺序考）时用。
填该题型内的题号范围，比如「第 20 题到第 45 题」。
**此时「数量」不参与**，题数完全由范围决定。

### 难度配比：让卷子难易可控

题库里有「难度」列时，这一块才出现。填各难度的权重：

> 易 5 / 中 3 / 难 2 → 各占 **50% / 30% / 20%**

同样，合计多少都行，会自动换算。三个都不填 = 不限难度。

某个难度的题不够时会**从其他难度借调并明确提示**，不会悄悄出一份偏难的卷子。
界面上会显示「题库中各难度题量：易 48　中 48　难 24」，填之前心里有数。

### 知识点覆盖：单元测验不偏科

题库里有「知识点」列时出现。勾选要考的章节，程序会：

1. 只在你勾选的考点里出题；
2. 尽量保证**每个考点至少出现一题**（避免某个冷门章节被完全跳过）。

不勾选 = 不限知识点。适合「这次要覆盖第一到第三章」这类需求。

### 题目不够了怎么办

要出的题比题库里的还多时，程序**不会偷偷少出**。你可以事先选好策略：

| 选项 | 行为 |
|------|------|
| **复用旧题并提示**（默认） | 把出过的题再拿来用，凑够数量，并告诉你哪些是复用的 |
| **少出题并提示** | 有多少出多少，并告诉你实际出了多少 |
| **直接报错** | 停下来，让你回去改配置 |

无论哪种都会给出明确提示。**不会出现「填了 100 题却只出了 30 题而毫无提示」**。

### 一次出多份卷子

「生成份数」填 3，就出 3 份卷子，并自动编号命名。

勾上「多份试卷不重复出题」后，三份卷子之间**不会出现重复的题**
（题库够的话，三份卷子的题目两两无交集）。这对同场考试分 A/B/C 卷很实用。

如果题库总题量不够三份都完全不重复，会按上面选的策略处理并提示。

### 排除历史已出过的题

勾上后，程序会记住你过去出过的题（记录在 `%APPDATA%\ExamPaperGen\history.json`），
本次组卷时自动避开。判断依据是题目**内容**，所以就算你重新排序、增删了题库里的行，
也依然认得出来。

历史记录可以在界面上查看和清空。

### 预览：看到的就是导出后的样子

右侧预览栏渲染的是**真正要导出的那个 PDF**，不是另做一套近似排版。
分页位置、换行、字体、行距与实际文件完全一致 —— 所见即所得。

改了任何配置，预览会自动刷新（有 400ms 防抖，不会边打字边卡）。

### 导出格式与纸张

- **试卷**：Word（`.docx`）与 PDF，两种格式的题目顺序与题号必然一致。
- **答题卡**：同样支持 Word 与 PDF。
- **纸张**：
  - **A4** —— 常规单页。
  - **A3 两张 A4 拼版** —— A3 横向，左半是第 1 页、右半是第 2 页。
    对折或从中间裁开，两边都是版心正常的 A4 试卷。适合一次印两张、省一半纸。
- **文件名可自定义**。默认叫「试卷」，生成「试卷-1.docx」「试卷-2.docx」；
  改成「三年级语文期末」就会得到对应名字，方便不同批次区分，不会互相覆盖。

**黑白打印友好**：所有文字纯黑，强调只用加粗、字号、实线，不使用浅灰填充
（复印后会变噪点），线宽不小于 0.6pt（再细的线打印机会丢）。

### 答题卡

面向**人工批改**设计，采用**填写式**而非涂卡圈：判断题写 `√`/`×`，
选择题直接写 `ABCD`。

为什么不用涂卡圈：涂卡圈是为机器读卡设计的，需要严格控制印刷精度才能涂准；
纯手工批改时它只是白白占地方。填写式同样题量下占用面积不到一半 ——
**120 题能压进一页 A4**，涂卡式要两三页。

答题卡上的题号与试卷**严格对应**（试卷里单选题是 6-10 题，答题卡上就是 6-10）。

### 模板与历史

- **模板**：把当前所有配置存成 JSON，下次一键恢复。经常出同类型卷子的话很省事。
- **历史**：每次导出都留记录（题目、份数、随机种子、输出文件），可以回查、清空。

## 准备你的 Excel 题库

### 必需的列

| 列名 | 说明 |
|------|------|
| **题型** | 填 `判断题` / `单选题` / `多选题` / `简答题`（必须与这四种完全一致） |
| **题目** | 题干文字 |
| **正确答案** | 见下方各题型说明 |

### 可选的列

| 列名 | 说明 |
|------|------|
| **选项A** ~ **选项E** | 选择题的选项。判断题、简答题留空即可 |
| **难度** | 任意文本标签，如 `易` / `中` / `难`。有这列才会出现「难度配比」 |
| **知识点** | 任意文本标签，如 `第一章 基础护理`。有这列才会出现「知识点覆盖」 |

### 各题型的答案怎么写

| 题型 | 正确答案列填什么 |
|------|------------------|
| 判断题 | `1`（对）或 `0`（错）。也接受 `√` `×` `对` `错` |
| 单选题 | 一个字母，如 `B` |
| 多选题 | 字母连着写，如 `ABD`（不加逗号或空格） |
| 简答题 | 参考答案全文，可以是一整段话 |

### 一个完整的例子

| 题型 | 题目 | 正确答案 | 难度 | 知识点 | 选项A | 选项B | 选项C | 选项D |
|------|------|----------|------|--------|-------|-------|-------|-------|
| 判断题 | “日”字是象形字。 | 1 | 易 | 第一章 拼音与汉字 | | | | |
| 单选题 | 《静夜思》的作者是？ | B | 易 | 第四章 古诗文积累 | 杜甫 | 李白 | 白居易 | 王维 |
| 多选题 | 下列属于中国四大名著的有？ | ABC | 中 | 第五章 文学常识 | 《红楼梦》 | 《西游记》 | 《水浒传》 | 《聊斋志异》 |
| 简答题 | 请写出“守株待兔”的意思，并说明它告诉我们什么道理。 | 守着树桩等待兔子撞上来。比喻死守狭隘经验、不知变通…… | 中 | 第二章 词语与成语 | | | | |

### 文件格式

- 支持 `.xlsx` / `.xlsm` / `.csv`
- CSV 会自动识别 UTF-8 和 GBK 编码，Excel 导出的中文 CSV 可以直接用
- **不支持 `.xls`（Excel 97-2003 老格式）** —— 用 Excel 另存为 `.xlsx` 即可

### 懒得从零开始？

程序里点「示例」会加载仓库自带的 `题库模板.xlsx`（小学语文，130 题，
四种题型齐全，含难度与知识点）。直接照着它改最快。

想换成别的学科，改 `tools/make_sample_bank.py` 里的题目内容后重新运行，
会重新生成这个模板文件。

## 常见问题

**改了配置，预览没反应？**
预览会自动刷新。如果长时间空白，检查是不是没选题型或没填数量 —— 这两种情况
预览栏会直接给出文字提示。

**生成的卷子里题目比我填的数量少？**
题库不够了。看界面顶部的提示条，它会说明缺多少、实际出了多少。
想避免这种情况，把「题目不够时」改成「直接报错」。

**导出后找不到文件？**
导出完成后的提示条可以点击，会直接在资源管理器里打开输出目录。
输出目录就在左侧「输出」区。

**发给别人用，对方打开是白屏？**
界面依赖 Windows 的 WebView2 运行时。Windows 11 必然自带；Windows 10 绝大多数
也已具备。确实缺失时，安装程序会提示并引导补装。

**能装在 U 盘里带走吗？**
可以，但要用免安装的文件夹版（`dist/ExamPaperGenerator/` 整个目录复制走即可，
双击里面的 exe 就能跑）。安装包版本会写进 `Program Files`，不适合移动使用。
两种版本的**用户数据**都存在 `%APPDATA%\ExamPaperGen`，换机器不会自动带过去。

**支持 Mac / Linux 吗？**
代码本身是跨平台的，但目前只针对 Windows 打包。源码运行在其他系统上理论可行，
需要自行解决中文字体路径差异，未做验证。

## 从源码运行

需要 Python 3.10 以上。

```bash
git clone https://github.com/Hermannmayer/Examination-paper-generation-system.git
cd Examination-paper-generation-system
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe main.py
```

不想开界面也可以用命令行批量出卷：

```bash
.venv/Scripts/python.exe -m app.cli --bank 题库模板.xlsx --out ./out \
    --judgment 10 --mcq 15 --multi 5 --answers --pdf --card
```

### 打包发行版

正式发行版由 GitHub Actions 自动构建，推一个 `v*` 标签即可：

```bash
git tag v1.0.0 && git push origin v1.0.0
```

CI 会依次跑测试、打包、自检，然后把安装包附到 Release。
本地调试用 `powershell -ExecutionPolicy Bypass -File packaging/build.ps1`。

> 开发相关说明（架构分层、两道产物自检、若干工程坑）都写在代码注释里，
> 有需要直接看 `main.py`、`packaging/exam.spec` 与 `ui/assets/css/app.css` 的头部注释。
